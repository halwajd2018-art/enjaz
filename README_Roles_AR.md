# إنجاز — تحديث صلاحيات رؤساء الأقسام

## ماذا يضيف التحديث؟

- في «الموظفون والأقسام»، يُعرض للمدير العام بجوار **رئيس القسم** زر «تحويل إلى موظف»، وبجوار الموظفين زر «تعيين رئيس قسم».
- لا يمكن أن يوجد **أكثر من رئيس قسم واحد للقسم**. عند وجود رئيس حالي، تُعطل ترقية موظف آخر في القسم، وتظهر رسالة باسم الرئيس الحالي؛ يجب تحويله إلى موظف أولًا ثم تعيين بديله.
- التغيير محصور في **المدير العام**، ولا يستطيع رئيس القسم منح نفسه أو غيره دورًا أعلى.
- طلب التأكيد يعرض اسم الموظف والقسم والدور الحالي والجديد قبل الاعتماد.
- تنتهي جلسات حساب الموظف الذي تغير دوره مباشرةً، ويلزم تسجيل دخوله مجددًا للصلاحية الجديدة.
- تبقى المهام والمرفقات والمراسلات وسجلات العمل التاريخية مرتبطة بالمستخدم نفسه دون حذف أو نقل تلقائي.
- يلتزم إنشاء الحسابات الفردي **واستيراد Excel** بالقاعدة نفسها، فلا يمكن استيراد رئيس ثانٍ للقسم ولا رئيسين للقسم نفسه من ملف واحد.
- يُحفظ كل تغيير دور في سجل التدقيق مع معرف الموظف والقسم والدور السابق والدور الجديد.

## مثال عملي لاستبدال رئيس قسم

1. سجّل الدخول بصلاحية المدير العام.
2. افتح «الموظفون والأقسام».
3. بجوار الرئيس الحالي اضغط «تحويل إلى موظف»، وراجع شاشة التأكيد ثم اعتمد.
4. ابحث عن الموظف المرشح في القسم نفسه واضغط «تعيين رئيس قسم» ثم اعتمد.
5. يسجّل الموظفان الدخول مجددًا بعد إنهاء الجلسات القديمة. يستمر سجل التكليفات السابق كما هو.

## تثبيت التحديث في GitHub

المستودع: https://github.com/halwajd2018-art/enjaz

1. فك الضغط عن الحزمة المرفقة.
2. ارفع ملفات `main.py` و`app.js` و`style.css` إلى **جذر** مستودع GitHub، مع الموافقة على استبدال الملفات المطابقة.
3. نفّذ Commit على فرع `main`. سيبدأ نشر Railway تلقائيًا.
4. راجع حالة `enjaz-app` في Railway: يجب أن تكون `SUCCESS`، ثم افتح https://enjaz.sharedsys.net واضغط `Ctrl+F5`.
5. **لا تعدّل** `Dockerfile` أو `requirements.txt` أو إعدادات PostgreSQL أو الدومين.

## الفحص والملاحظات

- التحديث مبني على أحدث نسخة محلية تضم البريد الداخلي والمرفقات ولوحة الحضور والاستيراد من Excel.
- اجتاز 7 اختبارات تطبيقية محلية (اختبارات الحزمة السابقة + اختبار جديد لتغيير الأدوار)، إلى جانب فحص Python وJavaScript.
- لم يُنشر التحديث على Railway أثناء إعداد الحزمة؛ التحقق النهائي من التشغيل يتبع تحديث GitHub.
- ضبط التزامن يتم بصف القسم المقفول خلال المعاملة في PostgreSQL عند تعيين رئيس. التعديلات المباشرة على قاعدة البيانات خارج التطبيق تتطلب ضبطًا إداريًا مستقلًا.
- يتعامل التحديث مع الرئيس الموقوف حسابه باعتباره رئيسًا مسجلًا؛ يجب تحويل دوره إلى موظف قبل اختيار بديل.
- لا يمكن تعيين حساب موظف موقوف رئيسًا حتى يُعاد تفعيله.
- لا يمكن نقل رئيس قسم إلى قسم آخر قبل تحويله إلى موظف.
