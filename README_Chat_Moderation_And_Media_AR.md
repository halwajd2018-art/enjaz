# إنجاز — تحديث إشراف المحادثات ومرفقات البريد الداخلي

**التاريخ:** 24 نوفمبر 2026م  
**المستودع:** https://github.com/halwajd2018-art/enjaz  
**الموقع:** https://enjaz.sharedsys.net

## 1. ما الذي يضيفه التحديث؟

1. **حذف الرسالة المخالفة داخل المحادثات** من خلال زر «حذف المخالفة» بجانب الرسالة مع طلب سبب الحذف وتأكيد الإجراء.
2. **صلاحية الإشراف:** المدير العام ومستشار القطاع يشرفان على المحادثة العامة وقنوات الأقسام كافة؛ رئيس القسم يشرف على المحادثة العامة وقناة قسمه. لا تمنح هذه الصلاحية الاطلاع على مناقشات المهام الخاصة لغير طرفَي التكليف. يستطيع صاحب الدور القيادي حذف رسالة ضمن مناقشة مهمة فقط إذا كان طرفًا فيها.
3. **الحذف المنطقي:** تُحجب رسالة المخالفة ومرفقاتها عن المشاركين ويحل محلها تنويه «تم حذف هذه الرسالة بواسطة الإشراف»، مع الحفاظ على السجل الأصلي وسبب الحذف وهوية منفّذه في قاعدة البيانات وسجل التدقيق. لا يُحذف سجل المحادثة بالكامل.
4. **مرفقات المحادثات:** إرسال صور JPG وPNG ومستندات PDF وDOCX وXLSX وPPTX وTXT وCSV مع الرسالة أو دون نص، مع عرض مصغّر للصور وتنزيل المستندات.
5. **مرفقات مناقشات المهام:** الإضافة نفسها مع الاحتفاظ بخصوصية مناقشة التكليف المستمرة.
6. **مرفقات البريد الداخلي:** إرفاق الصور والملفات عند إنشاء رسالة بريد داخلي وعند الرد داخل المراسلة نفسها، مع إبقاء المرفقات متاحة لطرفَي المراسلة فقط.

## 2. طريقة التثبيت على GitHub

1. خذ نسخة احتياطية من قاعدة بيانات PostgreSQL في Railway قبل التحديث؛ احرص ألا تتضمن النسخ الاحتياطية بيانات سرية متاحة للعامة.
2. فك ضغط ملف `Enjaz_Chat_Moderation_And_Media_Update.zip`.
3. افتح مستودع GitHub المذكور أعلاه، الفرع `main`.
4. **استبدل الملفات التالية في المجلد الرئيسي للمستودع:** `main.py` و`app.js` و`style.css`. لا تضعها في مجلد جديد.
5. اختر **Commit changes**. يبدأ Railway النشر تلقائيًا عند ربط المستودع بخدمة `enjaz-app`.
6. راقب حالة النشر، ثم افتح الموقع واضغط **Ctrl + F5** لتحديث ملفات الواجهة.

لا تعدّل `Dockerfile` أو `requirements.txt`؛ الإصدار الحالي يعمل مع ملفي Python وJavaScript المذكورين. عند التشغيل، ينشئ SQLAlchemy جدولَي `chat_moderations` و`shared_attachments` إذا لم يكونا موجودين، ولا يغيّر سجلات الرسائل القديمة.

**مهم:** النسخة تضم أحدث كود لتحديث إضافة «الإدارة العامة» وإصلاح إلغاء دور مستشار القطاع، حتى إذا لم يكن قد نُشر في المستودع سابقًا.

## 3. طريقة الاستخدام

- **مركز المحادثات:** اختر المحادثة، واكتب رسالة أو اختر الملفات ثم «إرسال». يظهر زر «حذف المخالفة» بجانب الرسائل لمن يمتلك الصلاحية.
- **مناقشة التكليف:** افتح المهمة ثم «مناقشة التكليف» وأرسل صورة أو ملفًا. تظل المحادثة خاصة ومستمرة تحت رقم المهمة نفسه.
- **البريد الوارد:** اختر «رسالة جديدة» أو افتح رسالة سابقة للرد، وأرفق الملفات. يمكن عرض الصورة المصغرة وتنزيل المرفقات بواسطة أطراف الرسالة فقط.

## 4. ضوابط السلامة والخصوصية

- الصيغ المسموحة: PDF، Word DOCX، Excel XLSX، PowerPoint PPTX، PNG، JPG/JPEG، TXT، CSV.
- الحد الأقصى **5 ميجابايت للملف الواحد** و**3 ملفات لكل رسالة أو رد**، و**50 ميجابايت لمرفقات سلسلة البريد الداخلي**.
- سقف تخزين تجريبي مشترك لمرفقات المهام والمحادثات والبريد **250 ميجابايت** حمايةً لحجم قاعدة البيانات الصغيرة في Railway.
- لا يمكن تنزيل ملف محادثة بعد حجب رسالته. تبقى البيانات الأصلية وأسباب الحذف محفوظة لأغراض التدقيق.
- لا تتيح صلاحية الإشراف للمدير أو المستشار قراءة البريد الداخلي الخاص بموظفين آخرين أو مناقشات مهام ليسا طرفًا فيها.
- فحص الصيغ والترويسات موجود، لكنه **ليس بديلًا عن خدمة فحص برمجيات خبيثة**. لا ترفع مستندات العمل الحساسة أو بيانات العملاء حتى تُعتمد المنصة والاستضافة وضوابط الحماية مؤسسيًا.
- نظام الملفات لا يرفع إلى Gmail أو Outlook؛ الإرسال والاستقبال داخل إنجاز فقط.

## 5. اختبار ما بعد النشر

1. سجل الدخول كموظف وأرسل صورة في المحادثة العامة؛ تأكد من ظهور الصورة وإمكان تنزيلها.
2. افتح المحادثة بحساب رئيس قسم، واحذف الرسالة بعد إدخال السبب؛ تأكد من حجب نصها ومرفقاتها.
3. حاول فتح الملف برابطه القديم بعد الحذف؛ يجب أن يظهر رفض الوصول.
4. أرسل مستندًا بالبريد الداخلي من حساب موظف لآخر؛ تأكد من رؤية المستلم للمرفق وعدم قدرة حساب ثالث على فتح الرابط.
5. أرسل ردًا مع صورة ضمن البريد نفسه؛ تأكد من حفظها ضمن السلسلة.
6. اختبر رئيس قسم آخر في قناة قسم غير قسمه؛ يجب أن يُرفض الوصول والحذف.
7. اختبر مناقشة مهمة خاصة؛ لا ينبغي للمدير أو المستشار الاطلاع عليها ما لم يكونا طرفًا فيها.

## 6. نتيجة الاختبار المحلي

نجحت **8 اختبارات تكامل** على حسابات تجريبية تشمل الحذف والصلاحيات والملفات والردود والخصوصية واستمرار واجهات إرسال الرسائل النصية السابقة. نجح أيضًا `python -m py_compile main.py` و`node --check app.js`.

**حالة النشر:** هذه الحزمة مُجهّزة فقط؛ لم تُرفع إلى GitHub أو تُنشر على Railway ضمن هذا التحديث.
