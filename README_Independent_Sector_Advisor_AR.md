# إنجاز — تحديث «مستشار القطاع» كوظيفة مستقلة دون قسم

## نطاق التحديث

**مستشار القطاع وظيفة مستقلة على مستوى القطاع، ولا يتبع أي قسم.** يحتفظ بصلاحيات مدير عام الإدارة في متابعة وإدارة المهام على مستوى جميع الأقسام، باستثناء إضافة الموظفين يدويًا أو استيرادهم من Excel، وباستثناء تعيين مستشارين آخرين أو تغيير صلاحية المدير العام. لا يتيح له الاطلاع على محادثات المهام أو المراسلات الخاصة التي لا يكون طرفًا فيها.

### آليات التشغيل

1. **إنشاء حساب جديد:** يختار المدير العام دور «مستشار القطاع» من نموذج إضافة مستخدم، فيختفي حقل «القسم»، ويحفظ الحساب دون قسم (`department_id = NULL`).
2. **ترقية موظف:** عند ترقية موظف إلى مستشار قطاع، يُزال ارتباطه بقسمه السابق تلقائيًا دون مسح مهامه أو مرفقاته أو مراسلاته.
3. **إلغاء دور المستشار:** عند إعادته إلى دور «موظف»، يجب على المدير العام اختيار القسم الجديد. لا يمكن تركه موظفًا دون قسم، ويُرفض طلب التحويل إذا لم يحدد قسمًا.
4. **المستشارون السابقون:** عند التشغيل الأول بعد التحديث، يفصل النظام تلقائيًا حسابات المستشارين الموجودة مسبقًا عن أقسامها مع إنشاء مدخلة في سجل التدقيق (`advisor_department_detached`)، دون تغيير أدوارها أو حذف سجلاتها.
5. **الاستيراد من Excel:** يجوز ترك عمود «القسم» فارغًا للمستشار. وإذا كان العمود معبأً بقسم من نموذج قديم، يُتجاهل ذلك الحقل ويُحفظ المستشار مستقلاً. أما الموظف ورئيس القسم فيلزم لكل منهما قسم.
6. **لوحة المتصلين:** يظهر المستشار في بطاقة منفصلة بعنوان «مستشار القطاع — وظيفة مستقلة»، لا ضمن بطاقة أي قسم أو بطاقة الإدارة العامة.
7. **تعديل الموظفين:** لا يجوز إسناد قسم لمستشار القطاع مباشرة؛ يجب سحب دوره وتعيين دور موظف واختيار قسم أولاً.

## التثبيت في GitHub وRailway

المستودع: https://github.com/halwajd2018-art/enjaz — الفرع `main`.

1. فك ضغط `Enjaz_Independent_Sector_Advisor_Update.zip`.
2. **استبدل هذه الملفات الثلاثة فقط في جذر مستودع GitHub**: `main.py` و`app.js` و`style.css`، بالنسخ الموجودة داخل الملف المضغوط.
3. نفذ `Commit changes` على الفرع `main`. سيبدأ النشر في Railway تلقائيًا.
4. تحقق من حالة `SUCCESS` ثم افتح https://enjaz.sharedsys.net واضغط `Ctrl + F5`.
5. من حساب المدير العام: راجع «الموظفون والأقسام»، واختبر إنشاء حساب مستشار دون قسم وفتح لوحة المتصلين، ثم جرّب تحويل مستشار إلى موظف مع اختيار قسم.

**لا تُعدل `Dockerfile` أو إعدادات `DATABASE_URL` أو جدول قاعدة البيانات يدويًا.** عمود القسم في قاعدة بيانات إنجاز قابل أصلًا لقيمة `NULL`، لذلك لا يلزم تعديل هيكل الجداول. النسخة تشمل كود إصلاح ارتباط المستشارين القدامى عند أول تشغيل.

## ضوابط أمنية وقيود التحقق

- سيحتفظ المستشار بجميع صلاحياته على مستوى القطاع، لكن إنشاء حسابات الموظفين يظل للمدير العام ورئيس القسم وفق القيود القائمة؛ لا يُسمح للمستشار بالإنشاء.
- التغييرات الصريحة للأدوار تُسجل في سجل التدقيق وتُنهى جلسات الحساب بعد تغيير دوره. ترحيل القسم للحسابات القديمة يسجل في التدقيق ولا يغير الدور.
- الاختبارات المحلية نجحت: 10 اختبارات موزعة على ملفات الاختبارات الأربعة، بما فيها اختبار مستقل لهذا التعديل، وكذلك `node --check` و`py_compile`.
- لم تُرفع هذه النسخة إلى GitHub أو Railway بعد. اختبار الإنتاج يستلزم النشر ومن ثم حسابات تجريبية.
- استخدم بيانات غير حساسة أثناء التجارب ولا ترفع بيانات العمل الحقيقية إلى استضافة خارجية دون اعتماد الجهة.
